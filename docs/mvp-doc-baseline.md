# v0.0.0-mvp-doc 文档基线与实现交接

本标签用于冻结宏原型开始之前的设计输入，包含 spec/RFC、Go 机制夹具和可复现研究。不是完整语言发布，也不表示审查风险已全部解决。本研究线程继续维护规格；独立实现会话基于此标签工作，将实现中发现的规范缺口回流。

## 已确认边界

- D21：宏、enum/match、只读/可写访问为 T0，分批交付；共享与内部可变考虑 std 显式容器，不预设全套 Box/Cell。
- D08：保留 GC Arc 方向；`mut&` 不承诺独占，`&T` 不承诺对象全局不变。基础权限须经过容器、方法和接口，不能靠长期分析补洞。
- D19/D20：别名/借用风险分析完全独立于 MVP，未来 warning-first，未知不普遍拒绝。不要求实现 W01–W04 子集或强制 effect 注解。
- D22：`?` 先支持 Option/Result；thiserror 生成显式 From，目标 Result 已知时一步转换，无转换链/任意泛型 blanket。静态 Go error 只走明确兜底或业务分类，不猜动态 variant。详见 [RFC 0005](rfcs/0005-option-result-question.md)。

## 未决语义不随标签冻结为已批准

| 问题 | 接续位置 / 实现约束 |
| --- | --- |
| 引用投影、受限容器/接口类型表示、方法接收权限 | U02/U03，RFC 0003；不得隐式恢复写权限，不引入独占准入 |
| 原生指针桥接、嵌套 ABI、AsPtr/unsafe | U05/U15，RFC 0002；A 仍候选，D11 不静默废除 |
| Arc 构造/投影、临时保留契约 | RFC 0003；H 未批准，不作为 MVP 门槛 |
| trait 一致性、重复声明、视图可选协议、字典/泛型 ABI | U04/U16，RFC 0004；D05/D06 仍现行，不按构建模式更换可观察语义 |
| enum 布局、原生共享存储读取合法值与发布边界 | U06/U08；不把一次校验说成永久不变量 |
| 宏 fragment/重复子集、卫生、格式协议、派生规则 | U09；原型明列支持和拒绝的语法，以真实输入→展开→Go 运行验收 |
| From 拼写、可见性/冲突与转换选择细则 | U17，RFC 0005；生成 Go helper 不等于问号前端已实现 |
| 增强依赖发布、缓存与普通 Go 下游消费 | U07/U12；根构建配置责任不能用普通 Go 输出掩盖 |

## 独立宏实现会话

推荐分支 `feat/macro-mvp`，从标签创建。目标为模式宏、log/tracing 风格结构化字段，以及 Debug/Clone/serde/thiserror 内建派生；JSON 为推荐首版格式。先选可执行语法子集，保留 token/AST、符号和源码位置，模式宏与派生模块可独立并行；不只生成固定样例，不声称 Rust 全兼容。完整 trait、enum、`?` 和借用分析不必同时实现；报告每种能力是端到端支持、Go 生成机制支持还是未实现。

## 证据与交付

运行 `python3 scripts/check_design.py --docs-only` 和完整入口，范围见 [tests](../tests/README.md)。Go 机制通过不证明 hgo 前端、宏卫生、类型权限或风险诊断。研究源码、原始基准、版本/命令和编译器输出保留于 [trait_paths](../tests/research/trait_paths/README.md)；总量约 280 KB，没有编译二进制或缓存。历史机器路径只作出处，复现入口自行建立临时模块。

标签仅在本地时，新云环境普通 clone/fetch 远端拿不到它。可选择之后授权推送该提交和标签，或授权传输 Git bundle 后在新环境校验并导入；当前不上传、不推送、不创建传输产物。bundle 应包含此标签及其所需历史，接收方先 `git bundle verify`，导入后核对标签解析的完整 commit SHA，再 `git switch -c feat/macro-mvp v0.0.0-mvp-doc`。不要将未提交工作区快照冒充此基线。
