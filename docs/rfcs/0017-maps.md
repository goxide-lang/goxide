# RFC 0017：多种 Map 实现与公共能力

## 状态与范围

用户提出通过 std 独立提供多种 Map 实现；本篇采用此推荐方向，API、协议名字及 ABI 仍是草案。
GoMap、HashMap、TreeMap 是区分实现需求的示意名，不代表已选定首版全部实现，也不是新增语言关键字。
本篇尚未实现。Vec 与 slice 视图见 [RFC 0010](0010-collections.md)，基础背景见[标准库专题](../design/standard-library.md)。

D19/D20 边界：读写权限和已确认类型不变量照常检查；别名、留存、独占与重入风险分析独立长期推进，不属 MVP。未来仅有具体风险证据才 warning；未知不默认拒绝或告警。

## 源级规则

Map 提供键到值的映射；公共协议表达共同操作，具体实现声明额外能力、约束和成本。
可以先共享长度、存在检查、查询副本、插入、删除及受限遍历；共同协议不默认承诺稳定元素地址。
GoMap 使用原生 Go map，需要适合 Go map 的键。HashMap 可采用明确的 Hash / Eq，TreeMap 可采用排序协议或比较器。
键的具体约束分别定义，不把 Go `comparable` 变成所有 Map 的语言要求。
有序遍历、并发操作、借用元素、稳定地址都是额外能力，不能仅凭类型名或相似方法签名推断。
Map 赋值也必须定义共享语义；包装一个 Go map 不会因为外面是 struct 就变成独立数据副本。

## 转译示例

以下使用拟议 API；各代码块为局部降低片段，支持类型及外部函数由所在示例上下文提供。

**MAP01：缺失查询返回 Option，不能暴露 V 的非法零值。**

```goxide
var scores GoMap[string, int] = GoMap::new()
score := scores.get_copy("missing") // Option::None
```

```go
// Option / Some 使用 RFC 0008 候选 A。
scores := make(map[string]int)
value, found := scores["missing"]
var score Option[int]
if found { score = Some[int]{Value: value} }
```

V 为 Result 时也只有 found 为 true 才暴露 value；生成代码中的临时 nil Result 不得成为源级结果。
get_copy 要求 V 可按该契约复制，元素内部指针等仍保留来源与共享关系。

**MAP02：删除可返回原值，并区分不存在。**

```goxide
removed := scores.remove("alice") // Option[int]
```

```go
previous, found := scores["alice"]
var removed Option[int]
if found {
    delete(scores, "alice")
    removed = Some[int]{Value: previous}
}
```

该 API 返回值遵守复制契约，不自动获得 V 可达对象的唯一所有权。并发版本需要另行定义操作原子性。

**MAP03：普通原生 map 不能直接实现原槽位写借用。**

```goxide
entry := scores.get_mut("alice") // GoMap 若未声明此能力，goxide 拒绝。
```

```go
entry := &scores["alice"] // Go 自身也拒绝：map 索引不可取址。
```

MAP03 不排除其他 Map 提供 get_mut。使用稳定 entry 单元可提供不同能力，例如候选 `map[K]*entry[V]`。
这个候选需要额外间接访问与可能的分配，并规定删除、替换、迭代及借用的相互约束。

**MAP04：复制后更新是可单独定义的协议。**

```goxide
scores.update_copy("alice", |old| old + 1)
```

```go
update := func(old int) int { return old + 1 }
old, found := scores["alice"]
if found {
    next := update(old)
    scores["alice"] = next
}
```

此候选约定：不存在时不调用回调；回调正常返回后替换槽位；panic 时不执行该次槽位写回。
这不回滚回调副作用或 old 内部共享对象的变化。重入访问同一映射须由库协议说明可观察行为，不因无法证明无冲突而默认拒绝。未来有具体重入风险依据才 warning。
该 API 不返回原槽位 mut&，也不适用于必须禁止值复制的 V；成本包含查询、值复制和写回。

## 拒绝与边界

**MAP05：删除后 entry 存活不等于仍属于映射。** 活跃引用本身不触发删除禁令；下例说明稳定单元候选的存储行为。

```goxide
stable.with_mut("alice", |entry| {
    stable.remove("alice") // 不因已有 entry 而默认拒绝；entry 可能成为已移除单元。
    use(entry)
})
```

```go
// 候选稳定单元存储：map[string]*Cell；假定 alice 存在且对应 Cell 非空。
entry := cells["alice"]
delete(cells, "alice")
use(entry) // Go 允许；GC 存活不等于仍代表该 map 的元素。
```

MAP05 不再沿用旧严格草案的静态拒绝；应验证删除后单元仍存活、但已不属于 map 的行为。最终 Map API 及稳定地址协议仍待定；有具体误用链才进入未来 warning 分析。
键的比较、哈希及遍历回调可能执行用户代码，lowering 须保持求值次数和副作用；显式调用效果照常检查。重入与留存风险不因未知而默认拒绝，不能把复杂效果摘要设为调用门票。
若迭代顺序有业务意义，应选择承诺该顺序的能力；原生 Go map 的遍历顺序不能提升为稳定顺序保证。

## 双向互操作

导入原生 `map[K]V` 可选择复制外层映射，或在声明契约下共享；复制不深复制 V 中的对象，共享不自动取得独占权限。
导出原始 map 会引入普通 Go 可用的别名，必须保留实际类型/访问资格边界并说明共享关系；不能提供无限制 raw 导出后仍宣称所有写入受 goxide 检查。
HashMap 或 TreeMap 转成原生 Go map 可能要求新的键约束、分配和逐项转换，不保证可行或零成本。
Go 调生成 Map API 仍遵循普通 Go 语义；goxide 的静态权限保证只针对经过 goxide 工具链检查并遵守外部契约的路径。
公共 trait 的实现选择、marker 或 wrapper 沿用 trait RFC；不另设按同名方法自动满足的 Map 协议。

## 验收与未定项

1. MAP01、MAP02 对存在、缺失、零值及严格 enum 元素给出正确 Option。
2. MAP03 明确缺失能力和 Go 不可寻址；MAP05 验证移除后的存活与成员身份变化，不要求静态借用拒绝。
3. MAP04 覆盖正常返回、不存在、panic 和内部共享对象副作用；重入行为依最终库协议验证，长期风险 warning 单独验收。
4. 各实现分别验证键约束、遍历顺序、删除与引用所指单元的关系，不强求不具备的能力。
5. 未定：首版具体实现、公共 trait、赋值 / Clone、借用返回、迭代协议及并发版本。
6. 本篇不保证所有 Map 共享相同布局、复杂度或元素引用能力。
